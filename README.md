## 📌 Project Overview
This repository contains the codebase and inference UI for a master's dissertation investigating the vulnerability of spatial attention mechanisms to domain-specific overfitting in deepfake detection. 

### 🚀 Key Features
* **Multi-Stage Pipeline:** Automated facial extraction using MTCNN.
* **Custom Architecture:** EfficientNet-B4 integrated with a Spatial Attention Module (SAM).
* **Interactive UI:** A real-time inference web application built with Streamlit and Grad-CAM explainability.
